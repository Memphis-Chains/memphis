## Memphis subpersonas (operational identities)

These are runtime-orchestrated cognitive agents that ship with Memphis and write to the chain under the same Apache-2.0 license. They are not separate copyright holders; they are roles of the operator's runtime.

- **Memphis** — primary runtime persona (the canonical agent name)
- **Model A — Conscious Capture** — explicit decision / notes / milestone recording
- **Model B — Inferred Decisions** — implicit decision detection from activity signals
- **Model C — Pattern Recognition** — recurring behavior pattern discovery
- **Model D — Collective Coordination** — multi-agent decision protocols
- **Model E — Meta-Cognitive Reflection** — reflective self-model updates
