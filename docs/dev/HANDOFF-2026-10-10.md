## `automerge` — działa od 2026-10-10 14:44

Przez całą sesję nie scalił niczego. Cztery błędy, każdy blokował merge
niezależnie od tego, co odpaliło job:

1. **Brak triggera na koniec checków.** Ocenialiśmy raz, gdy `chain-invariant`
   jeszcze biegł, i nic nas obudziło. → `workflow_run`/`schedule`.
2. **`workflow_dispatch` wpadał w `else`**, który czyta `PR_NUMBER` — a
   payload go nie ma. „No pull request number in the event payload".
3. **`echo "number="` vs `steps.pr.outputs.pr_number`** — dwie nazwy tej samej
   rzeczy. `PR_NUMBER` przychodził pusty, `gh pr merge ""` padał z „could not
   determine current branch". Testy tego nie widziały, bo obie strony czytały
   ten sam plik. Teraz jest test porównujący zbiory kluczy.
4. **Job-level `if` nie przepuszczał triggera bez PR-a** — na `schedule`
   `github.event.pull_request` to null, a dereferencja null w `if` to błąd,
   nie fałsz.

Dowód, że działa: PR #675 zmergowany przez `gh workflow run automerge.yml`,
run `38148381382`, `conclusion: success`.
