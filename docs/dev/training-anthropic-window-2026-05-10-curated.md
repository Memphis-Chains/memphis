## Quality tags (preserved in records, NOT filtered)

Every record has `_quality`:
- **`full`** — 8 turns. Thinking ≥20 chars + all tool results succeeded. Best signal.
- **`thin`** — 74 turns (after balance: 14). Thinking <20 chars. MiniMax-M2.7 style: dispatches without explicit chain-of-thought.
- **`failed`** — 20 turns (after balance: 4). Tool result had error/non-zero exit. Useful for **error-recovery training**.

**Thinking-length distribution (raw 102 deduped):**
- 0 chars: **93** (91%!) — bot dispatched naked, zero reasoning text
- 11-50: 4
- 51-200: 4
- 200+: 1

**Implication:** MiniMax-M2.7 is **highly elliptic** in CoT — dispatches tool immediately on user input. If the goal is teaching Kartograf/Watra to generate visible reasoning, this dataset alone won't teach it (no reasoning to imitate). If the goal is teaching **tool routing** (input → tool choice), the dataset is fine — labels are present.

## Limits + augmentation path

**This dataset is tiny.** 21 train + 5 eval is **demo-scale**, not production training. Use as:
1. Pipeline smoke test (verify training loop loads correctly)
2. Schema reference (downstream sessions follow same format)
3. Seed for active-learning loop (operator labels more in similar format)

**To scale:**
- **Wider window:** lift `created_at >= '2026-05-10'` to e.g. `'2026-04-01'` — captures full April→May. Probably ~500-1000 tool turns. Run same curate.py.
- **Other surfaces:** `primary::http:*`, `worker-session-*` if present. Check `SELECT DISTINCT session_id FROM operator_chat_messages` in SQLite.
- **Synthetic negatives:** generate "what NOT to dispatch" pairs via prompt engineering on system prompt + operator queries.
- **Chain-block aug:** chain blocks (in `~/.memphis/chains/`) are 6500+ blocks. For zone classifier, those are already the v1 Kartograf corpus.
