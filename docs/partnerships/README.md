## Recommended submission flow (5-15 minutes)

1. Open `combined-pack.html` in browser
2. Click "Kopiuj" on title, paste into new GitHub issue title
3. Click "Kopiuj" on body, paste into GitHub issue body
4. Submit to: https://github.com/MiniMax-AI/minimax-code/issues/new
5. (Parallel) Open `outreach-packet.md`, fill out Sales track on https://platform.minimax.io/contact-us
6. Pin the issue → notifications enabled
7. Wait 1-7 days for `@hetaoBackend` (release coordinator) to respond

**Expected scenarios:**
- Optimistic (5-15%): redirect to BD team → follow-up via email
- Realistic (60-70%): OSS Part A accepted with maintainer PR; Part B ignored or redirected
- No response (15-20%): escalate after 14 days via Discord (agent-plugins-spec community)

## Anti-confab (per issue body we submitted)

**We are NOT asking for:**
- Funding
- Investment
- Equity dilution
- Special API pricing
- Exclusive territory rights
- NDA
- Joint entity formation

**We ARE asking for:**
- Partner-level API allocation (vs public token-plan)
- Brand permission for Polish market
- One named contact
- Short pilot letter ("partner during pilot, no commitment past 90 days")
- Maintainer PR with attribution to our commit `c32c23f` (OSS contribution)

**Pilot scope:** 90 days, 3 paying Polish B2B customers, baseline MRR ≥ 5,000 EUR.
