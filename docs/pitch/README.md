## Bilingual approach

- **Polish** in section headers, captions, and metric labels
- **English** in main body copy
- **Why:** Polish prospect opens deck, sees Polish structural markers + sees English technical details they trust. Both audiences served from one file.

## How to regenerate PDF after edits

```bash
cd ~/memphis/docs/pitch
libreoffice --headless --convert-to pdf memphis-watra-minimax-pitch-deck.html
```

(Output overwrites the existing PDF.)

## How to use

**Email:** attach the PDF to your outreach email — it's a self-contained pitch deck.

**Print:** A4 landscape, color printer recommended. Each slide is one page (some overflow to second page; check before printing).

**Present:** open the PDF in fullscreen mode (F11 in most viewers).

**Web:** open the HTML in any browser — same content, slightly different rendering.
