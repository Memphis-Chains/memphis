Rozwiązanie · What Memphis is

A sovereign agent runtime. Chain-backed memory. Native MiniMax integration. Polish sales.

What it does · Co robi

Memphis runs on operator hardware (Linux/macOS/WSL2), uses content-addressed chains for durable memory, encrypts secrets with pepper + master-key rotation, and integrates with minimax-code via @mavis/memphis-collective.

  • Local-first — no telemetry, no analytics
  • Encrypted vault — secrets never leave the host
  • 7 chain types — journal, decisions, cases, …
  • HALT guard — every destructive op audited
  • 23+ MCP tools — typed, auditable

What it does not do · Czego nie robi

Memphis is not a SaaS. There is no cloud, no remote control, no telemetry. The runtime does not phone home. Even the optional MiniMax API calls are opt-in per session.

  • Does NOT call any remote service by default
  • Does NOT collect analytics or metrics
  • Does NOT require a MiniMax account to run
  • Does NOT lock you into any vendor's model
  • Does NOT need internet to function
