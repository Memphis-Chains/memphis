## 13 punktów

### 1. ✅ Sovereign runtime baseline — **2026 Q1-Q2**

Lokalny agent: rdzeń Rust + orkiestracja TypeScript, szyfrowany vault (AES-256-GCM), append-only chains z podpisem Ed25519. Brak chmurowego lock-in. Operator może wyłączyć Internet — agent dalej działa.

**Evidence:** v1.8.0 release tag (2026-05-02), `crates/memphis-core/`, `crates/memphis-napi/`, `~/.memphis/vault-entries.json`.

### 2. ✅ Memory architecture — **2026 Q1-Q2**

11 łańcuchów (journal, decisions, soul, system, cases, patterns, reflections, insights, collective, proactive, messages). Embedding semantic recall (Kartograf v1, ModernBERT 150M, ONNX). FTS5 exact search. Wszystko hash-linked, cryptographically verifiable.

**Evidence:** `~/.memphis/chains/`, `crates/memphis-napi/src/lib.rs:69`, `docs/dev/KARTOGRAF-SPEC.md` (frozen).

### 3. ✅ Multi-surface gateway — **2026 Q2**

TUI (Rust ratatui) jako natywna konsola operatora. Telegram bot z voice + photo handling. CLI z 50+ komendami. HTTP API z bearer-auth. MCP server (stdio + HTTP) dla zewnętrznych klientów.

**Evidence:** `crates/memphis-tui/` (8k LOC), `src/gateway/channels/telegram.ts`, `src/infra/cli/`, `src/mcp/server.ts`.

### 4. ✅ Voice stack 100% local — **2026 Q2**

Polski voice end-to-end na boxie operatora: faster-whisper STT (medium INT8) + Piper TTS z głosem `pl_PL-gosia-medium` (kobiecy, default) lub `pl_PL-darkman-medium` (męski). Per-request override przez `X-Voice` header. One-shot installer.

**Evidence:** PR #455-#458 (`memphis voice install`), `scripts/voice-install.sh`, `docs/operator/voice-local-stt.md` + `voice-local-tts.md`.

### 5. ✅ Anti-confab + audit-grade transparency — **2026 Q2**

Każda odpowiedź na każdej powierzchni kończy się footerem `— via {provider}/{model}` — operator wie kto wygenerował tekst. System-prompt zabrania botowi claimować tożsamość modelu z intuicji albo fabrykować liczb status'u. Reasoning blocks (`<think>...</think>`) filtrowane na granicy gateway'a.

**Evidence:** PR #463 (provider stamp + system-prompt guards), #464 (real labels), #467 (think filter).

### 6. ⏳ One-liner install + automated bootstrap — **2026 Q2**

Czysta maszyna → operator console w 5 minut: `curl ... | bash` → `memphis init` → `memphis service install` → `memphis tui`. Polish quickstart + smoke verifier shipped. **Wymaga jeszcze:** weryfikacji na clean Ubuntu LTS VM (Sprint C #4 z `Y1 roadmap v3.1`).

**Evidence:** PR #468 (Wątek A install audit), `scripts/install.sh`, `INSTALL.md` + `INSTALL.pl.md`, `scripts/post-install-smoke.sh`, `docs/operator/QUICKSTART.md`.

### 7. 🔬 Kartograf v1 nightly retrain (Watrowanie) — **2026 Q3**

Kartograf embed model dotrenowuje się co noc na nowych chain deltach: 70% static corpus + 30% recent deltas (catastrophic-forgetting guard), LoRA 1 mini-epoka, eval gate przed promote, atomic ONNX swap pod symlink `~/.memphis/kartograf/active.onnx`. Na 4 GB VRAM GTX 960.

**Evidence:** `docs/dev/KARTOGRAF-SPEC.md` § "Watrowanie nightly target" (frozen). Brak kodu retrain pipeline'u — Q3 sprint.

### 8. 🔬 Federation Matrix — private peer sync — **2026 Q3-Q4**

Dwie maszyny operatora (Station ↔ Nomad, np. desktop + laptop) synchronizują checkpoints + chain deltas przez Matrix HMAC. Bez central server — każdy peer ma own keypair. `--source federation` flag w CLI ready.

**Evidence:** `Y1 roadmap v3.1` N14 spec, `src/federation/mp/envelope.ts`, `src/federation/mp/operator-key.ts`. Pełny kod do dodania Q2-Q3.

### 9. ⏳ `.mv2` archival + portability — **2026 Q3**

Format `.mv2` (Memphis vault v2) — kompletny eksport vault'a + chains + sesji do jednego pliku, signed Ed25519 + szyfrowane content. Operator może przenieść runtime między maszynami / archive na USB / inspekcja przez audit. Round-trip read/write reproducible.

**Evidence:** PR #434 (Q1 scaffold — kod istnieje), `crates/memphis-export/src/mv2/{writer,reader,tracks}.rs`. Q1 round-trip test pending Q2.

### 10. 🔬 Memphis Language v1 GA — **2027 Q1**

Memphis-ML — Lisp-like DSL z pełną semantyką języka (zmienne, funkcje, lambdy, pętle, rekurencja) kompilowany do bytecode'u na stack-based Rust VM. 10 crates: vm, p2p, protocol, hal (GPIO/HTTP/MQTT), ml-memphis (chain integration), cli. Programy ML mogą wywoływać tooli Memphis + komunikować się peer-to-peer przez Matrix transport.

**Evidence:** `~/memphis-ml/` repo (working VM, 10 crates), `MEMPHIS_ARCHITECTURE_LAYERS.md` § "memphis-ml". Brak public release'a — Y2 milestone.

### 11. 🔬 Kartograf v2 — on-device LoRA fine-tune — **2027 Q1-Q2**

Operator wybiera mały lokalny model bazowy (Polka-1.1B, Qwen2.5-0.5B, SmolLM2 — wybór per-domain), Memphis fine-tune'uje go LoRA'mi na własnych chains operatora, output to GGUF konsumowany przez istniejący Ollama provider — zerowy core code change. Eval gate na 100 golden prompts (BLEU + tool-call accuracy).

**Alternatywa:** `Bielik-distill` (Speakleash 11B → 1B class via cloud teacher distillation). Zarezerwowane jako 11b — wymaga decyzji operatora o budgecie cloud (RunPod ~$10-50 jednorazowy training).

**Evidence:** `docs/dev/KARTOGRAF-SPEC.md` (v1 baseline), `docs/dev/KARTOGRAF-LLM-DISTILL.md` (planowany research doc). Code: TBD Y2.

### 12. 🔬 LeWorldModel perception layer — **2027 Q2-Q3**

15M parameter JEPA (AMI Labs 2026) jako warstwa percepcji dla sensor data — CNC controllery (Efka/PFAFF), audio environment, IoT. Trenuje się single-GPU (~3h na GTX 960). Violation-of-expectation alerts → chain `world_model`. Federowane checkpoints przez ten sam Matrix transport co Kartograf. Zero new transport, zero new signature scheme.

**Evidence:** `docs/dev/LEWM-INTEGRATION-PROPOSAL.md` (PR #466, 405-line spec). Code: greenfield Y2 sprint.

### 13. 📐 Agora public market — **2027 Q4 → 2028**

Decentralized discovery + reputation + stake + DHT dla artefaktów Memphis: Kartograf checkpoints, LeWM checkpoints, Memphis-ML programs. Operatorzy stakują własne modele, inni oceniają jakość transfer-learning. **MVP scope:** 5-10 agentów, prosty marketplace, rozbudowa per traffic. **Świadome wyłączenie:** to nie blockchain, tylko peer reputation.

**Evidence:** `Y1 roadmap v3.1` N16+, `--source agora` CLI flag już shipped (zwraca "Y2+ deferred"). Code: design-stage. Realny start ~2028 jeśli MVP demand się pojawi.

## Co dalej w 2028+ (mgliście)

Roadmap **na pewno** się zmieni po Q1 2027. Realistyczne kierunki:
- Multi-modal fusion (#11 + #12 łączą się)
- Hardware control demos (Memphis-ML + LeWM razem napędzają realne maszyny)
- Operator network beyond MVP (jeśli Agora znajdzie traffic)

Co **nie** jest obietnicą: AGI, GPU farm, podbój rynku. Memphis pozostaje narzędziem operatora — nie produktem dla mas.
