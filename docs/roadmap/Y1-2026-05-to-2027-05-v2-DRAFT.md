## Context

**Why this exists.** Memphis v1.5.0 (shipped 2026-04-22) is the production-ready baseline. The gap now is not "README vs code reality" (v1 theme) — it's "Memphis doesn't yet understand its own structure semantically". Every safety gate is hardcoded, every embedding is generic, every routing decision is operator-driven. The Y1 goal is to close that gap with **Kartograf** — a Memphis-native mini model that knows the codebase, its boundaries, and what operators actually ask.

**Two design shifts from v1:**
1. **One AI track, not three.** v1 had Watra-pointer (Q3) + embedding cascade (Q2) + Ollama chat (ongoing) as separate tracks. v2 fuses retrieval + routing + safety into Kartograf (one model, multi-head outputs); keeps reasoning separate as a router over multiple providers.
2. **Synchronized convergence over parallel features.** Each quarter ships a complete thesis, not a bag of features. Q1 = data-as-asset. Q2 = semantic runtime. Q3 = cognitive layer. Q4 = lab-grade product.

**Product pipeline at steady state:**

```
Memphis chains ──► .mv2 export ──► Kartograf corpus ──► nightly Watrowanie ──► Kartograf v1.N
     ▲                                                                              │
     │                                                                              ▼
     │                         ┌──────────────────────────────────────────────────┐
     │                         │  Reasoning router (Kartograf zone + complexity)  │
     │                         ├──────────────────────────────────────────────────┤
     │                         │  online → RLM sandbox + Claude/GPT/etc           │
     │                         │  offline → Ollama local + Kartograf retrieval    │
     │                         └──────────────────────────────────────────────────┘
     │                                        │
     └──── operator feedback + corrections ◄──┘
```

**Hardware envelope (hard constraint):** target host 4 GB VRAM + CPU offload + 8-16 GB RAM + Intel i3-class. Every deployed model must fit 4 GB VRAM at inference. Training can escape to cloud (user directive: local preferred, cloud as fallback when accuracy requires).

**Security is continuous, not a milestone.** Per-PR checkbox + per-sprint delta + per-quarter posture snapshot. External review engagement Q2.

## Non-negotiable principles (v2)

1. **Rust core authoritative.** `crates/memphis-core|memphis-operator|memphis-embed|memphis-kartograf` (new Q2) own data plane; TS orchestrates via NAPI.
2. **Own the stack with dep class discipline.** Classes: `stdlib` / `stable-platform` / `vendored-frozen` / `scheduled-for-rewrite` / `blocked`. No Dependabot auto-merge. memvid-core stays `stable-platform` (v2.0 pinned). ModernBERT weights `stable-platform` (HuggingFace pinned revision). transformers/peft/bitsandbytes `stable-platform`.
3. **No new formats if one exists and is ownable.** `.mv2` via memvid-core is substrate.
4. **Every README promise shippable today.**
5. **Every stub explicit.** No silent `throw new Error('not yet')`.
6. **Commercial-ready license hygiene.** Apache-2.0 main. Zero GPL/AGPL. CLA Q4. Commercial fork Y2 Q2.
7. **Kartograf is a classifier, not an agent.** Emits structured outputs (embedding + zone probs + safety score). Cannot call tools, cannot write chains, cannot generate free-form text (advisory head is bounded-length + retrieval-grounded). Paranoid tier by construction — classifier outputs flow through same operator gate as any query result.
8. **Vault never enters training corpus.** Hard invariant. Corpus pipeline enforces allowlist of source paths + secret-pattern scan (api keys, tokens, PEM blocks, JWTs) before tokenization. Vault state files explicitly denylisted. Every Watrowanie run logs corpus-scan summary to `watrowanie_runs` chain.
9. **Security per-PR + per-sprint + per-quarter.** External review Q2.
10. **Consent defaults per chain** — decisions/reflections/patterns exportable; journal/cases local-only. Vault/secrets/private: always excluded.
11. **Local-first for training AND inference.** GTX 960 is baseline target. Cloud is escape hatch for accuracy-critical training runs (Kartograf v1 initial train), explicitly NOT the default.
12. **Reasoning layer is hybrid by design.** Online path (RLM + frontier) for complex analysis; offline path (Kartograf retrieval + Ollama local) always works without internet. Automatic routing via Kartograf zone + network check.

No additional Phase 0 research required to start Q1.

**Workstream C — Kartograf spec + corpus curation (NEW, replaces v1 WATRA workstream structure)**

`docs/dev/KARTOGRAF-SPEC.md` covers:
- **Zone taxonomy (9 + 3 reserved):** `core`, `vault`, `chain`, `tools`, `cognitive`, `config`, `docs`, `test`, `glue`, `reserved_1`, `reserved_2`, `reserved_3`.
- **Vector layout (256d):**
  ```
  dims[0:9]    zone distribution (softmax)
  dims[9]      mutability_score (0=invariant, 1=freely editable)
  dims[10]     operator_facing (binary)
  dims[11]     safety_boundary (0=touch-freely, 1=never-auto-edit)
  dims[12]     subsystem_confidence (classifier entropy proxy)
  dims[13:256] free semantic content (contrastive trained)
  ```
- **Multi-task loss:**
  ```
  L = λ1 · contrastive(dims[13:])                    # InfoNCE
    + λ2 · cross_entropy(dims[0:9], zone_label)
    + λ3 · mse(dims[9], git_age_normalized)
    + λ4 · bce(dims[10], operator_facing_label)
    + λ5 · bce(dims[11], safety_invariant_label)
    + λ6 · orthogonality_penalty(supervised, free)   # prevent leakage
  ```
- **Scaffold:** ModernBERT-base (150M, Apache-2.0, HuggingFace pinned revision, 8k context, encoder-only).
- **Training strategy (two paths, decision gate end of Q2 week 2):**
  - **Path A (default, local):** LoRA on ModernBERT base + full-train multi-task heads. GTX 960 BF16 batch=4-8 via gradient accumulation. ~1-2GB VRAM. Estimated 4-8h overnight.
  - **Path B (escape, cloud):** Full-parameter fine-tune on H100 spot instance, ~2-4h wall-clock, $20-100 one-off. Chosen only if Path A's v0.1 checkpoint fails eval threshold (retrieval P@10 < 0.6 OR zone accuracy < 80%).
- **Inference:** FP16 on 4GB VRAM; can also run CPU for headless deploys (~100ms per query).

**Corpus pipeline (`tools/training/kartograf-corpus.py`):**
1. **Source allowlist** (ONLY these paths enter):
   ```
   src/**/*.{ts,rs}
   crates/**/*.rs
   docs/**/*.md
   tests/**/*.ts
   ~/.memphis/chains/*.jsonl    (chain content, but with step 2 filter)
   ~/.memphis/config/ISKRA.md   (operator identity, allowed)
   ~/.memphis/config/PULSE.md
   ```
2. **Explicit denylist** (hard refuse):
   ```
   ~/.memphis/vault/**
   ~/.memphis/config/*.env
   .env*
   **/secrets/**
   **/.memphis-backup*/**
   ```
3. **Secret-pattern scan** (regex, fail-closed): AKIA\*, AIza\*, ghp_\*, sk-ant-\*, xox[baprs]-\*, JWT patterns, PEM blocks, `api[_-]?key\s*[:=]\s*"..."`, `password\s*[:=]\s*"..."`. Any match → sample rejected + logged.
4. **Zone auto-label** via path heuristics (`src/security/**` → zone_vault, safety=0.95; `src/chains/**` → zone_chain; etc. per KARTOGRAF-SPEC).
5. **Mutability label** from `git log --format=%at -- <file>` → normalized against repo age.
6. **Teacher distillation** for ambiguous files: Claude API call with file content (redacted) + zone taxonomy → label returned + cached. Budget: ~500-2000 API calls for full Memphis repo, ~$10-50 one-off.
7. **Pair generation** for contrastive: positive pairs from co-occurrence in git commits + similar symbols; hard negatives from different zones.
8. **Output**: JSONL per split, zone-labels map, license-audit JSON (classification + license per sample), summary `corpus-v1-summary.json`.

**Workstream D — RLM sandbox spec (NEW, design-only Q1)**

`docs/dev/RLM-SAFETY-INVARIANTS.md` covers:
- **Sandbox contract:** Python 3.11 subprocess via `pyproject` with `RestrictedPython` AST filter + resource limits (`resource.setrlimit`) + no network namespace + read-only FS mount for `~/.memphis/chains/` + whitelist `memphis_*` function table.
- **Tool whitelist** (Q3 impl, listed here):
  - `memphis_chain_query(chain, filter?, limit?)` — read
  - `memphis_recall(query, limit?, chain?)` — read
  - `memphis_search(query, limit?, chain?)` — read
  - `llm_query(prompt)` — recursive call (paper's primary primitive)
  - `FINAL(answer)` / `FINAL_VAR(name)` — terminate trajectory
- **Hard budgets:**
  - Max sub-calls per trajectory: 50
  - Max wall clock: 180s
  - Max tokens (input + output cumulative): 50000
  - Max recursion depth: 1 (paper's tested depth)
- **AST pre-check:** before each code block execution, parse Python AST, reject if touches non-whitelist names or dangerous builtins (`eval`, `exec`, `open`, `__import__`, `compile`, `os`, `subprocess`, `sys.modules`).
- **Audit chain:** new `rlm_execution` chain type. Every trajectory → entry with `{trajectory_id, query, sub_calls, duration_ms, tokens_used, final_answer, code_hash, outcome: success|budget_exceeded|ast_rejected|error}`.
- **Content sanitization:** chain data passed to `context` REPL variable is escaped (strip markdown code blocks, strip shell injection patterns, strip ANSI control).
- **Preview mode:** `memphis reason --preview <query>` generates code without executing — operator confirms before run (default for queries targeting `zone_vault` or `safety_boundary > 0.8`).
- **Fallback:** any budget exceeded / AST rejected / runtime error → automatic fallback to direct RAG (Kartograf retrieval + primary LLM answer) with warning.

Q1 deliverable: spec doc only. Impl in Q3 (sync C).

**Workstream A — RLM sandbox (N33 NEW, MAJOR)**

- `crates/memphis-repl-sandbox/` — Rust wrapper over Python 3.11 subprocess.

async function routeReason(query: string, opts?: ReasonOpts): Promise<ReasonPath> {
  const emb = await kartograf.embed(query);
  const networkOk = await probeNetwork({ timeout: 500 });
  const mode = opts?.mode ?? 'auto';

  if (mode === 'offline' || !networkOk) return 'offline:ollama+kartograf';
  if (opts?.preview || emb.zones.vault > 0.5) return 'online:rlm+preview';
  if (complexityScore(emb) > COMPLEX_THRESHOLD) return 'online:rlm';

}

## Kartograf — technical spec (Q1 doc, Q2 impl)

### Role (locked)

Unified Memphis-native AI layer. Encoder-only mini-model (ModernBERT-base scaffold, 150M params). One forward pass produces: (1) dense embedding for retrieval, (2) zone distribution for routing, (3) safety boundary for destructive-op gate, (4) mutability score for self-modify confidence, (5) optional short advisory response (opt-in head). Runs 4 GB VRAM inference; FP16 ~300MB on disk.

### Training data hard invariants

- **Vault never enters corpus.** Path denylist + secret-pattern scan per Q1 Workstream C. Every corpus build logs scan summary; any leak detected → abort + Telegram alert.
- **License compatibility.** Only Apache-2.0 / MIT / similar permissive inputs. GPL / LGPL / commercial-restricted filtered via license audit.
- **Provenance.** Each sample carries `{source_path, license, zone_label, mutability, secret_scan: clean}` metadata. Stored alongside corpus.

### Base role boundary

Kartograf is **a classifier**. What it cannot do:
- No tool invocation.
- No chain writes.
- No free-form text generation (advisory head is bounded-length + grounded in retrieved Memphis docs; not open LLM).
- No cloud egress (local inference only).

### Pointer emission (replaces Watra pointer)

```ts
{
  chain: ZoneName,              // argmax over zones[0:9] if zone-like query
  selector: string,              // extracted keyword/phrase from query
  reasoning: string,             // entropy-weighted explanation
  confidence: number,            // zone softmax peak
  alternatives?: Array<{chain, selector, confidence}>, // runner-ups if entropy high
  embedding: Float32Array,       // 256d (for callers who want raw similarity)
  safetyBoundary: number,        // cautionary signal
  timestamp: string
}
```

Validated by Zod schema `src/kartograf/pointer.ts`. Exposed as:
- CLI: `memphis kartograf query "<text>" --json`
- Tool registry: `memphis_kartograf_pointer` (tier-0 read, replaces planned `memphis_watra_pointer`)
- API: `src/kartograf/router.ts::queryPointer(natural: string)`

### Hardware envelope (inference)

| Deployment | VRAM | Latency target |
|---|---|---|
| GTX 960 4GB FP16 | ~350 MB | < 200ms |
| CPU-only (i3-class) | 0 (RAM ~400 MB) | < 500ms |
| Cloud ephemeral | variable | < 50ms |

Coexists with Ollama 7b (Q4_K_M ~4.5GB if separate card; CPU offload if shared). Ollama→Kartograf handoff on same card requires Ollama unload/reload (handled via existing provider cascade logic).

### Training envelope

| Path | Compute | Wall clock | Params trained | Budget |
|---|---|---|---|---|
| A (local default) | GTX 960 4GB BF16 | 8-24h over 3 nights | LoRA (~5M) + heads (~5M) | $0 |
| B (cloud escape) | H100 spot | 2-4h | full 150M | $20-100 |

Path A is default. Path B activates only if Path A fails eval thresholds (P@10 < 0.6 or zone acc < 80%).

### Eval protocol

Held-out 1000-query eval set (mix: 300 retrieval, 300 zone classification, 200 safety calibration, 200 mutability correlation). Metrics:
- Retrieval P@10 ≥ 0.75 (v1 target)
- Zone classification accuracy ≥ 0.90 (v1 target)
- Safety calibration ECE < 0.05
- Mutability rank correlation Spearman ρ ≥ 0.7

Eval runs pre-release + continuously in Watrowanie gate.

## RLM safety invariants (Q1 doc, Q3 impl)

Full spec: `docs/dev/RLM-SAFETY-INVARIANTS.md` (Q1 deliverable).

Key binding constraints:
1. **Sandbox isolation is non-negotiable.** No filesystem writes outside scratch tmpfs; no network; no subprocess spawn; no dangerous Python builtins.
2. **AST pre-check before execution.** Every code block parsed; any non-whitelist call → reject.
3. **Hard budgets enforced kernel-side** (`resource.setrlimit`), not just in user code.
4. **Recursion depth = 1** (aligns with paper's tested depth). Deeper recursion deferred to Y2 with additional safety review.
5. **Preview mode default** for queries touching `zone_vault` or `safety_boundary > 0.8` (Kartograf-detected).
6. **Audit chain** (`rlm_execution`) captures every trajectory with full code hash, outcome, budget utilization. Consent default `local-only`.
7. **Fallback is mandatory** on any sandbox failure — degrade to direct RAG (Kartograf retrieval + answer) with operator-visible warning, never silent failure.
