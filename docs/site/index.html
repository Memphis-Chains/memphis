Co to jest · What it is

Memphis to osobisty runtime dla jednego operatora.

Nie SaaS. Nie platforma. Nie startup szukający inwestora. To środowisko uruchomieniowe z rodzaju tych, które instalujesz lokalnie na Linux/macOS/WSL2, uruchamiasz jednym poleceniem, i od tej pamięci agenta zależy Twoja codzienna praca.

Co Memphis robi

  • Pamięta decyzje w 7 content-addressed łańcuchach
  • Trzyma sekrety w encrypted vault (pepper + master-key rotation)
  • Ma 20 natywnych tooli dostępnych przez MCP
  • Integruje się z agent-plugins-spec (Cursor, OpenCode, Mavis-compatible)
  • Guarduje destrukcyjne operacje przez HALT-aware destructive ops
  • Audit chain w JSONL — każdy tool call zapisany

Czego Memphis NIE jest

  • NIE jest SaaS-em ani platformą z chmury
  • NIE jest wrapperem na cokolwiek (M3/M2.7 są opcjonalne)
  • NIE telemetruje — zero outbound calls w default install
  • NIE szuka pieniędzy, equity, ani partnerów inwestycyjnych
  • NIE wymaga internetu do działania (lokal-first)
  • NIE jest vendor-locked — audytowalne end-to-end

HALT-aware destructive ops · co wyróżnia Memphis

Skill, którego inne runtime'y nie mają.

Powstał po incydencie z 2026-09-22, gdy agent peer usunął plik objęty council-request HALT bez koordynacji. Memphis nie ufa agentom — nawet sobie. Każdy rm, mv, git rm jest sprawdzany przed wykonaniem.

Jak to działa

HALT registry w ~/.memphis/halt/ — jeden plik JSON na wstrzymany zasób. Plik = SHA-256 ścieżki, więc deterministic, no path conflicts.

Pre-flight guard (check.sh) — wywoływany przed destrukcyjnymi operacjami. Jeśli argument pasuje do halted resource → exit 1, operacja zablokowana.

Audit JSONL w ~/.memphis/audit/halt/events.jsonl — każde sprawdzenie (pass/block/bypass) zapisane. Append-only.

Bash hook — opcjonalny DEBUG trap w ~/.bashrc guarduje automatycznie. Dla nie-bash agentów: explicit halt_rm / halt_mv.

Cron integrity — memphis-halt-integrity.timer codziennie 09:00 sprawdza czy halted files istnieją. Wykrywa jeśli inny agent usunął resource bez zgody.

Bypass conscious — HALT_BYPASS=1 HALT_BYPASS_REASON='...' rm file loguje powód i przepuszcza. Anti-hubris: bypass jest logowany ale nie cryptographically gated.

Integracja · agent-plugins-spec

Plugin format, nie proprietary fork.

Memphis opakowuje się w Agent Plugins v1.0.0 spec — otwarty standard z TSC zawierającym Amazon, Cursor, Microsoft, OpenAI, Vercel. To znaczy że Memphis capabilities są kompatybilne z każdym conformant client bez vendor lock-in.

Co to daje

  • Memphis = plugin dla Mavis (minimax-code)
  • Te same skille działają w Cursor, OpenCode, innych conformant clients
  • Plugin capabilities: tools, hooks, skills, agents
  • Otwarty governance przez GitHub Discussions
  • Zero lock-in — jeśli Memphis nie pasuje, plug-out i tyle
