# Legacy TypeScript TUI Archive

This directory preserves the pre-Rust TypeScript TUI as historical reference only.

Current product truth:

- `memphis tui` launches the Rust console
- active TUI code lives in `crates/memphis-tui` on top of `crates/memphis-operator`
- files under `legacy/tui-ts/` are not part of the active runtime, active test suite, or release validation path

Keep this archive only for traceability, historical diffs, and post-release cleanup work.
