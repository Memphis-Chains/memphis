Czego agent nie robi

  • Nie indeksuje /docs/internal/, /panel/, /panel-app/.
  • Nie traktuje Memphis jako hostowanego SaaS-u.
  • Nie wysyła sekretów poza środowisko operatora.
  • Nie miesza oferty Holiskool z open-source frontem Memphis.
local vault

Token vault dla osobistego agenta

Bezpieczna granica: ten formularz zapisuje dane lokalnie w `localStorage` po zaszyfrowaniu hasłem w przeglądarce. Nie ma backendu, uploadu ani logowania na serwer. To nie jest produkcyjny identity provider — to agent-friendly placeholder pod przyszły prawdziwy Memphis vault.

Uwaga: nie wklejaj cudzych tokenów ani produkcyjnych sekretów, jeśli nie kontrolujesz tego urządzenia/profilu przeglądarki.
