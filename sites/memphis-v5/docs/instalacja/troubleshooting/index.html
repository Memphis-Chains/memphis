    Rozwiązywanie problemów#

    Złota reguła#

    memphis doctor --json

    doctor diagnozuje integralność chainów, vault, providerów, service i SQLite indeksów. --fix próbuje naprawić to co bezpieczne do naprawy.

    Częste problemy#

    memphis: command not found#

    Installer linkuje CLI do ~/.local/bin/memphis albo /usr/local/bin/memphis. Sprawdź $PATH:

    echo $PATH | tr ':' '\n' | grep -E "(local|\.local)"

    Jeśli brak — dodaj w ~/.bashrc / ~/.zshrc: 

    export PATH="$HOME/.local/bin:$PATH"

    vault.integrity.breach przy starcie#

    BLAKE3 hash sealed state nie zgadza się. Możliwe przyczyny:

    1. Inny passphrase — pomyłka, spróbuj ponownie.
    2. Uszkodzony plik — data/vault-entries.json skopiowany częściowo.
    3. Tampering — ktoś (lub proces) modyfikował plik.
    memphis vault verify          # oddzielna weryfikacja
memphis doctor --deep         # sprawdza też backupy

    Jeśli masz backup vaultu — memphis vault restore <path>.

    chain.integrity.breach#

    Chain wykrył niezgodność prev_hash. Memphis blokuje write'y do tego chaina. Nie nadpisuj — zgłoś w ops chain i podjmij decyzję:

    memphis chain verify --type journal --verbose
memphis chain quarantine <chain>   # izolacja do decyzji
memphis chain replay <chain>        # regeneracja SQLite indeksu

    Ollama nie odpowiada#

    systemctl --user status ollama   # Linux
launchctl list | grep ollama     # macOS

    memphis providers test --local sprawdzi routing przez cascade.

    Provider cloudowy odmawia#

    • Rate limit → Memphis automatycznie cascade'uje do następnego.
    • API key unieważniony → memphis vault list + memphis vault add <provider>_api_key.
    • TOS violation → memphis providers disable <name> i bez łez.

    Zapomniany passphrase#

    Nie ma magicznego odzyskania. Są dwie opcje:

    • Recovery Q/A jeśli ustawione: memphis vault recovery-unlock.
    • Rip & reinit — strata vaultu (sekrety), ale chainy zostają (public vera integrity). Re-add secrets manualnie.

    Logi#

    memphis service logs -n 500 --since 1h
journalctl --user -u memphis.service -n 200 -f   # Linux systemd

    Escalate#

    Jeśli doctor --fix nie pomaga i logi są dziwne — otwórz issue z outputem memphis diag bundle (generuje redacted tarball) na GitHub.
